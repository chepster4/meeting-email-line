One funny single-line joke about a meeting that should have been an email — an entry for the [make.fun bounty "The Meeting That Should Have Been an Email"](https://make.fun/bounty/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9).

## The line

> Nobody read the email, so we held a meeting where the host read it to seven grown adults like a bedtime story.

## How it works

`main.ts` (Node 22, standard library only, no network) writes the line above to `/output/entry.txt`. The program is fully deterministic: every run produces the exact same bytes.

## Run

```sh
node main.ts
```

The line is written to `/output/entry.txt` — a single line of 110 characters, UTF-8, with no trailing newline.
